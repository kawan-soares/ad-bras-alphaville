# AD Brás Alphaville

Site oficial da **AD Brás Alphaville**, Campo de Itapevi, Ministério de Madureira.

📍 Alameda Amazonas, 686 · Alphaville - SP

## Estrutura

```
index.html      → página completa (HTML + CSS + JS)
images/         → logo, fundo e fotos
```

## Como editar

Endereço, Instagram, e-mail, WhatsApp, telefone e horários de culto ficam no bloco `CONFIG`, no final do `index.html`.

Fotos da galeria: adicione `images/galeria-1.jpg` até `images/galeria-8.jpg`.
